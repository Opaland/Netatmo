# Revue multi-personas · fin de v1.5

*Version évaluée : **v1.5, livrée** (novembre 2026). Revue de **fin de version** : elle juge ce qui a été
livré par rapport au [cadrage v1.5](v1.5-cadrage.md). La v1.5 est la première des deux versions de
qualité de la [feuille de route](../../PROJET.md#9-feuille-de-route-v14-à-v16) : revue de code
complète et corrections, plus les suites de l'audit des données côté collecte, **sans nouvelle vue**.*

**Méthode.** Les 62 personas du cadrage v1.4, mêmes numéros et familles. Chaque verdict porte sur l'écart
**v1.4 → v1.5** lu dans les PR fusionnées (#287, #288, #289, #321 à #324, #326 à #329 pour le code ;
#286, #307, #320, #325 pour les études et la préparation de la v1.6) et les issues fermées du jalon,
pas sur les intentions. 👍 la version répond à son besoin, 👎 non, ➖ hors cible ou neutre. Une version
de qualité sans nouvelle vue laisse logiquement **neutres** les personas qui attendent une fonction
visible : un ➖ ici ne signale pas un recul. Comme en v1.4, les nouvelles collectes sont testées sur
l'API simulée et la démo ; leur vérification sur le vrai compte (diagnostic « Inventaire ») reste à
faire. Chaque persona a reçu un commentaire « Revue de fin de version v1.5 » sur son issue, avec son
vœu principal pour la suite, et son issue passe au jalon v1.6.
